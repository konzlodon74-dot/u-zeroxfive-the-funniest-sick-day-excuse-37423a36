# The Parrot Meeting

A single-line sick-day excuse for the make.fun bounty "The Funniest Sick-Day Excuse". The program writes one line to `/output/entry.txt`: a worker who cannot make it in because their parrot has learned to say "meeting in five" and has kept them in back-to-back calls since 6am. It is half believable — parrots really do mimic office phrases — fresh, and the laugh lands on the last word, as if typed in a hurry by a real person messaging their boss.
